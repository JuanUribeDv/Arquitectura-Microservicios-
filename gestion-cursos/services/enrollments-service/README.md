# Enrollments Service

Microservicio para la matrícula e inscripción de estudiantes en cursos.

## Funcionalidades

- Inscripción de estudiantes
- Consulta de matrículas
- Validación de cupos
- Historial académico

## Endpoints sugeridos

- `GET /api/enrollments`
- `POST /api/enrollments`
- `DELETE /api/enrollments/:id`
